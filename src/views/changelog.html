Changelog

Historial de cambios, mejoras y nuevas funcionalidades

v1.1.0
Octubre 14, 2025

Mejoras Críticas de Producción

Actualización mayor enfocada en seguridad, escalabilidad y experiencia de usuario.

  • Seguridad Aislamiento de usuarios: Cada usuario ahora tiene sus propios presupuestos completamente aislados. Privacidad y seguridad garantizadas.
  • Seguridad Rate limiting mejorado: Sistema de límite de peticiones con ventana deslizante (10 mensajes por minuto). Incluye limpieza automática de memoria.
  • Seguridad Validación de configuración con Zod: La aplicación valida todas las variables de entorno al iniciar. Fail-fast con mensajes claros de error.
  • Nuevo Web de documentación: Interfaz web minimalista estilo iOS 18 con documentación completa, ejemplos interactivos y búsqueda en vivo.
  • Nuevo API de status: Endpoint /api/status para monitoreo del estado del bot en tiempo real.
  • Mejora Auto-registro de usuarios: Los usuarios se crean automáticamente al enviar su primer mensaje. Sin formularios, experiencia fluida.
  • Mejora Tracking de última interacción: El sistema registra la última vez que cada usuario interactuó con el bot.
  • Fix Módulos ESM: Corrección de imports para compatibilidad total con Node.js ESM (type: "module").
v1.0.0
Septiembre 16, 2025

Lanzamiento Inicial

Primera versión estable de Finance Bot con funcionalidades core completas.

  • Nuevo Múltiples presupuestos: Crea y gestiona tantos presupuestos como necesites.
  • Nuevo Registro de ingresos y gastos: Comandos simples para registrar movimientos financieros.
  • Nuevo Categorización: Organiza tus movimientos con categorías y hashtags.
  • Nuevo Consultas en tiempo real: Revisa el estado de tus presupuestos y movimientos instantáneamente.
  • Nuevo Multi-plataforma: Soporte completo para Telegram y WhatsApp.
  • Nuevo Parser conversacional: Usa lenguaje natural para interactuar con el bot.
  • Nuevo MongoDB backend: Base de datos escalable y confiable.
  • Nuevo Arquitectura modular: Diseño limpio con Domain-Driven Design.
